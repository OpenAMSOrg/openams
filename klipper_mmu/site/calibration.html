Calibration  /  buffer, tube and selector

Measure once, on your machine.

The unit decides when filament has arrived, and whether a failed load was a blockage or a slip, from measurements only you can take: what your buffer reads relaxed and compressed, and how long your Bowden tube is. Selector units also need their gate positions.

  1. The buffer, by hand, with the safe image and motor power off.
  2. The Bowden tube, measured by the unit. Needs the motion image, and a calibrated buffer, because arrival is read from the buffer.
  3. Selector gates, on linear, rotary and servo selector units.

The buffer

The OpenAMS buffer sits between the unit and the extruder. Its sensor sends two voltages, which klipper-mmu turns into one number from 0 to 1000:

ReadingMeaning
0Relaxed. Slack and tension both read 0; the buffer only senses compression.
about 500Printing. The unit feeds faster or slower to hold the middle.
700Arrived. During a load, passing 700 and staying there means the tip has reached the extruder.
1000Fully compressed. A load that gets here stops with an error.

Every sensor and magnet gives slightly different voltages, so you show the unit what 0 and 1000 look like on yours. The unit will not finish starting up until you do.

Taking readings

Flash the safe image, switch off motor power, and use only the probe in printer.cfg:

[klipper_mmu box]
mcu: mcu
diff_probe: True

Restart Klipper. Hold the buffer still at a known position and read it:

KLIPPER_MMU_DIFF_PROBE MMU=box

Note a_raw, b_raw and the position. Take 2 to 8 readings, in order from relaxed to fully compressed, always including both ends. Three to five is plenty. Let the buffer settle before each reading, and skip any reading identical to the previous one.

The calibration file

Write the readings to a file such as ~/printer_data/config/box-diff-calibration.json:

{
  "channel_map": "a_low_b_high",
  "vref_mv": 3300,
  "min_valid_mv": LOWEST_GOOD_MV,
  "max_valid_mv": HIGHEST_GOOD_MV,
  "path_tolerance_counts": TOLERANCE,
  "points": [
    { "a_raw": A_RELAXED,  "b_raw": B_RELAXED,  "position_permille": 0 },
    { "a_raw": A_HALFWAY,  "b_raw": B_HALFWAY,  "position_permille": 500 },
    { "a_raw": A_SQUASHED, "b_raw": B_SQUASHED, "position_permille": 1000 }
  ]
}
FieldMeaning
pointsYour readings, in order. a_raw/b_raw as printed by the probe; position_permille from 0 (relaxed) to 1000 (fully compressed).
channel_mapWhich signal is the low one. a_low_b_high on a standard BoxTurtle; b_low_a_high if b_raw is the smaller number.
vref_mvThe ADC range: 3300 for 0–3.3 V.
min_valid_mv, max_valid_mvThe lowest and highest voltage a healthy sensor produces. Outside them means a broken wire or short, and the reading is rejected.
path_tolerance_countsHow far the two signals may disagree with the calibration before a reading counts as broken (1–4095).

Klipper checks the file at start-up and refuses it if a rule is broken:

RuleDetail
Point count2 to 8
PositionsFirst is 0, last is 1000, each one further than the one before
Raw valuesWhole numbers 0–4095, exactly as printed (not millivolts)
OrderNeither raw value goes down from one point to the next, and no two points are identical

Reset the board (the probe holds the sensor until then), and replace diff_probe: True with:

diagnostic_startup: True
diff_calibration_file: ~/printer_data/config/box-diff-calibration.json
Use your own readings

Readings from an example or another buffer describe a different magnet. They will produce a confident, wrong calibration.

Checking it

Restart Klipper. KLIPPER_MMU_QUERY MMU=box should show startup_state=ready. Then run the buffer check, and within about 10 seconds push the buffer fully in and release it:

KLIPPER_MMU_COMMISSION MMU=box STEP=fps

A good calibration rises from near 0 past 900 and returns near its start. The quick start lists what each complaint means.

The Bowden tube

LOAD is refused until the tube from the hub to the extruder has been measured. This moves filament, so it needs the motion image and the OpenAMS settings from the quick start. Add a file for the result:

bowden_estimate_file: ~/printer_data/config/box-bowden.json

Restart Klipper. With nothing past the hub and filament in any lane n:

KLIPPER_MMU_CALIBRATE MMU=box BAY=n

The unit feeds past the hub at crawl speed until the buffer sees arrival, retracts behind the hub, and reports the length in millimetres. Put that number in openams_path_length_mm. The path is shared, so one lane calibrates all lanes. The result is used immediately, saved to the file, and restored at every restart. A measurement never retries: if it fails, it stops and says why.

The arrival window

After calibration, a load must see arrival within ±50 mm of the measured length (KLIPPER_MMU_LOAD_WINDOW_MM in the menu). Before calibration the only bounds are 100–1900 mm past the hub.

  • Too early: something is in the way (a kink, a closed idler), or the tube is now shorter.
  • Too late: the drive is slipping, a tube came loose, or the buffer is not responding.

The measurement includes a little compression and slip, so it is close to the tube's length, not exact. Measure with a clean, straight path.

When to measure again

  • Buffer: after replacing or moving the buffer, its magnet, sensor, cable or board, or when the buffer check is no longer clean.
  • Tube: after changing or re-routing the tube, recalibrating the buffer, or changing the firmware.

The unit discards a saved tube length by itself when the buffer calibration file or the firmware's settings change. It cannot notice a new tube.

Per-lane rotation distance

Every lane's drive gear is assumed identical, but real gears vary a little from wear or printed-part tolerance. If one lane consistently over- or under-feeds, calibrate lane 0 first, then check each other lane against it with SAVE=0 so it does not disturb lane 0's saved tube length (they share one measurement), and adjust that lane's own feeder_rotation_distances entry:

KLIPPER_MMU_CALIBRATE MMU=box BAY=0
KLIPPER_MMU_CALIBRATE MMU=box BAY=1 SAVE=0

The second command's report names the suggested new rotation distance for lane 1. Put it in feeder_rotation_distances (millimetres, one per lane, blank entries keep the firmware's own default), restart Klipper, and calibrate lane 0 again to check the whole path is still within its arrival window.

Selector gates

Linear, rotary and servo selector units ship with default gate positions from Happy Hare's configuration. For linear selectors (ERCF, Tradrack) these are estimates from CAD geometry, not measurements. Calibrate before trusting them. Add a file for the results:

selector_calibration_file: ~/printer_data/config/box-selector.json
Selector kindHow to calibrate
Linear, rotaryRun KLIPPER_MMU_MOTORS_OFF, move the selector by hand to gate n, then run KLIPPER_MMU_CALIBRATE_SELECTOR GATE=n. It homes, measures the travel and saves it. Do gate 0 and the last gate first; the gates between are spaced evenly.
ServoFind each gate's angle with KLIPPER_MMU_SERVO ANGLE=a, then save it with KLIPPER_MMU_CALIBRATE_SELECTOR GATE=n ANGLE=a. Add SPACING=s to fill the other gates s degrees apart.
IndexedNothing to calibrate. Each gate is found by its own switch. Set the gate order and switch width in the menu.

Add SAVE=0 to measure without saving. A position outside the selector's travel or angle range is refused. The saved table is tied to your firmware build and is not applied to a different image. A gate with no calibration can still be configured; only selecting it is refused.

You can also enter positions directly, in selector microsteps, one per gate: selector_gate_steps: 320, 2160, 4000, …. Saved calibration takes precedence.

When it complains

Message or symptomWhat to do
Startup never reaches readyNo calibration, or the file was refused. Check diff_calibration_file and the rules above.
Probe reports no fresh readingWait and ask again. If it persists, check diff_probe: True and the buffer cable.
Probe stops working after a config changeThe probe holds the sensor until the board resets. Reset the board, then restart Klipper.
Load stops “before the calibrated minimum”Arrived too early: a kink or obstruction, or the tube got shorter. Fix it, then measure the tube again if you changed it.
Load stops with “no resistance” past the hubArrived too late: slipping drive, loose tube, or the buffer is not responding. Run the buffer check first.
Load reaches fully compressedThe buffer calibration is usually off. Take the readings again.
Tube measurement failedIt never retries. Read the reason, fix it, and run it again.
“gate N is not calibrated”That selector gate has no saved position or angle. Calibrate it.

For anything else, KLIPPER_MMU_DIAGNOSE MMU=box explains the current state, and When things go wrong has the recovery order.
