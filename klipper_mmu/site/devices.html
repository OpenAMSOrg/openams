Supported units

Which units, and how they work.

Every unit below runs on the same control core. Its differences (how it picks a lane, which sensors it has, its speeds and gearing) are data, taken from Happy Hare's and AFC's own configurations for that unit.

Supported means software

Each unit builds, starts and passes a whole-system simulation. None has been qualified on real hardware yet. Stock Bambu AMS units and OpenAMS keep their own firmware; klipper-mmu does not run on them.

How a unit picks a lane

KindHow it selects a laneUnits
Feeder per laneEach lane has its own feeder motor. Nothing moves between lanes.BoxTurtle, NightOwl, EMU, KMS, QIDI Box, Angry Beaver, 3MS, QuattroBox
LinearA stepper moves a carriage to the gate's position; a servo grips the filament against one shared gear.ERCF, Tradrack
RotaryA stepper turns a selector to the gate; the shared gear turns the way that gate needs.3D Chameleon, HTLF, MMX6
ServoA servo swings to the gate's angle. No selector stepper.MMX, Low Rider, Pico MMU
IndexedA stepper turns until the wanted gate's own switch triggers. No position table to calibrate.BTT ViViD, Claymore

Selector units home on the first selection after start-up or after a fault. Linear, rotary and servo units need their gate positions calibrated; indexed units do not. See Calibration.

Sensors

A unit uses the sensors it has and refuses operations that need one it lacks. It never assumes a reading from a missing sensor.

SensorWhat the unit uses it for
BAY switch (per lane)Filament is inserted in that lane.
LOAD switch (per lane)The feeder has gripped the filament. On EMU and KMS it is also the hub.
HUB switchFilament has reached the point where all lanes meet.
Toolhead switchFilament has reached the extruder (arrival).
Buffer (FPS)Compression during a load means arrival; during a print it sets the follow speed. Switched or analog.
EncoderClicks as filament moves. No click over 10 mm of gear travel is a stall.

A load ends on the unit's own board: at a local toolhead switch, or when the buffer compresses. A sensor on another board (for example a toolhead switch wired to the printer's toolhead MCU) cannot end a load. Wire it to the MMU's board instead.

Units without a BAY switch

Angry Beaver, 3MS and QuattroBox cannot see whether a lane has filament. They follow Happy Hare's rule: each gate is unknown, available or empty. An unknown gate is tried. A load that succeeds marks it available; a load that finds no filament marks it empty. You can set it yourself with KLIPPER_MMU_SET_GATE_METADATA GATE=n AVAILABLE=0|1. EJECT backs the lane out by a set distance (20 mm; 1500 mm on 3MS) and marks the gate empty, as Happy Hare does.

Chips and boards

You choose the chip first, in Klipper's own menu. A board preset only fills in default pins; you can change every pin.

  • STM32H723 (AFC Lite): every unit.
  • STM32G0B0 / G0B1 (BTT MMB): Angry Beaver, ERCF 2.0 and ERCF 3.0, the units Happy Hare ships on the MMB. On these 128 KiB chips, klipper-mmu's own code is built for size so it fits.
  • F207, F405, F407, F429, F765, G431, G474, H743, H750: NightOwl and the generic Custom profile.

The menu needs a chip with at least 128 KiB of flash. Options a chip cannot support (for example an analog buffer without enough ADC inputs) are hidden or refused at build time.

klipper-mmu is an optional add-on to Klipper, a separate project with its own authors and license (GPL-3.0). It builds on the work of the Happy Hare, AFC, BoxTurtle and OpenAMS projects.
