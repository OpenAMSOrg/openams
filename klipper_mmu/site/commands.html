Commands  /  every KLIPPER_MMU_* command

Every command, in one place.

Every command takes MMU= with the name of your [klipper_mmu …] section; the examples use MMU=box. A command either does what it says or refuses and says why. The Moves column says whether it can move anything.

Moving filament

Your prints load through OpenAMS, not through these commands:

OAMSM_LOAD_TO_TOOLHEAD GROUP=T0

GROUP is a tool from your filament_group sections. OpenAMS picks the lane; klipper-mmu does the feeding, watches the buffer and stops on arrival, with up to three attempts. Unloading and tool changes are OpenAMS commands too.

The spool commands below take BAY=n (lanes count from 0) to start. Without BAY they report the current or last result; CANCEL=1 cancels one that is running.

CommandWhat it doesMoves
KLIPPER_MMU_PRELOAD BAY=nPull a newly inserted spool into its bay and park it, checking the lane grips and sees it.Yes
KLIPPER_MMU_UNPRELOAD BAY=nBack a parked spool out of the feeder.Yes
KLIPPER_MMU_EJECT BAY=nWind a lane's filament all the way back so the spool can come out. Refused while that lane is in the shared path. Units without BAY switches back out a set distance instead.Yes

Selector

Only on units with a selector. See Calibration.

CommandWhat it doesMoves
KLIPPER_MMU_HOMEHome the selector. Rarely needed: the first selection after start-up or a fault homes by itself. Refused with filament in the shared path.Selector
KLIPPER_MMU_MOTORS_OFFRelease the selector motor so you can move it by hand. The next selection homes again. Refused while anything is moving.No
KLIPPER_MMU_CALIBRATE_SELECTOR GATE=nLinear/rotary: home from a hand-placed gate and save its position. With ANGLE=a (servo): save that angle; SPACING=s fills the other gates. SAVE=0 only reports. Refused on indexed selectors.Selector
KLIPPER_MMU_SERVO ANGLE=aMove a servo selector to a test angle. Selects nothing and saves nothing.Servo

Setting up and checking

CommandWhat it doesMoves
KLIPPER_MMU_DIFF_PROBERead the analog buffer's raw pair once, for the calibration file.No
KLIPPER_MMU_COMMISSION STEP=switchesCheck every switch with no filament loaded.No
KLIPPER_MMU_COMMISSION STEP=fpsSample the buffer for about 10 s while you push it.No
KLIPPER_MMU_COMMISSION STEP=lane LANE=nWait for filament in lane n, then preload and eject it. Record the spool's rewind with ANSWER=yes|no.Yes
KLIPPER_MMU_CALIBRATE BAY=nMeasure the Bowden tube from the hub to arrival. Required before LOAD.Yes

Recovering

Use them in this order: diagnose, ACK_FAULT, RESTART_DRIVER if a driver failed, RECONCILE_PATH, then RECOVER_SESSION. None of them moves anything or resumes a print by itself.

CommandWhat it doesMoves
KLIPPER_MMU_ACK_FAULTAcknowledge a fault once the lane has stopped. Does not clear the fault.No
KLIPPER_MMU_RESTART_DRIVER LANE=nRestart a lane's motor driver after fixing the cause. SELECTOR=1 restarts the selector's driver instead. Never enables a motor.No
KLIPPER_MMU_RECONCILE_PATH ACTION=CLEARState that the shared path is empty. Fresh sensor readings must agree. Clears a stopped fault once everything is acknowledged.No
KLIPPER_MMU_RECONCILE_PATH ACTION=ADOPT LANE=nState that lane n is in the shared path. Checked the same way.No
KLIPPER_MMU_RECOVER_SESSIONRelease the old connection record so a new print session can start.No
KLIPPER_MMU_RECOVER_LOCALAfter a dropped connection or a host stall over 2 s: finish a stranded preload, unpreload or eject result. DIAGNOSE names the case.No
KLIPPER_MMU_RECOVER_WAITERThe same, for a request that was still waiting for its outcome.No

Your own notes

Information you record yourself. The unit does not infer it from sensors, except gate status on units without BAY switches.

CommandWhat it doesMoves
KLIPPER_MMU_SET_GATE_METADATA GATE=nRecord NAME, MATERIAL, COLOR and AVAILABLE for a gate. On units without BAY switches, AVAILABLE is the gate status (see Supported units).No
KLIPPER_MMU_TOOL_MAP TOOL=t GATE=nMap a slicer tool to a gate. CLEAR=1 removes it; no GATE reports it.No
KLIPPER_MMU_MAINTENANCEYour own wear counters: COUNTER=name with INCR, RESET=1, LIMIT, WARNING. No arguments lists them.No

Switching commands on

If Klipper says it does not know a command, the option that enables it is probably missing. Restart Klipper after adding one.

Option in [klipper_mmu box]Enables
diff_probe: TrueDIFF_PROBE. For buffer calibration only; remove it afterwards or start-up waits for more readings.
diagnostic_startup: TrueHosted start-up and the startup_state fields.
openams_motion: True + OpenAMS optionsPreload, unpreload, eject, calibrate, the lane check, selector commands and recovery.
bowden_estimate_fileSaving the measured tube length.
selector_calibration_fileSaving selector gate calibration.
driver_restart: TrueRESTART_DRIVER
path_reconciliation: TrueRECONCILE_PATH
gate_metadata_file, tool_mapping_file, maintenance_counters_fileThe three note-keeping commands.
