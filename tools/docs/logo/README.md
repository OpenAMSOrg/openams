# OpenAMS logo

Four filaments, one per AMS bay, spiral inside a circle. Each filament is a
stroke led by its spool, a round dot. Line and dot share a colour, the four
colours differ, and the four arms have 4-fold rotational symmetry, so the mark
turns. It is the flat, vector successor of the glossy `logo_background.png`
swirl, and uses the same palette.

Everything is generated by `generate.py` (Python 3, standard library only).
Each arm's centre line is an Archimedean spiral fitted with cubic Beziers (the
fit is within 0.01 viewBox units). Open `preview.html` to compare the three
directions, small sizes, and the mark in a docs top bar and a browser tab.

## Chosen: A3, "Rim"

Each dot is a **spool** and each line its **filament**: the spool is large and
solid, and the filament leaves it at the rim, the way filament comes off a real
spool, not from its centre. It was chosen on 2026-10-09 over A, "Sweep"
(small dots leading thicker lines) and A2, "Spool" (large dots on the line's
end).

| parameter | value | at 16 px |
|---|---|---|
| arms | 4, bay order red, amber, blue, green, placed counter-clockwise | |
| spiral | Archimedean, 0.41 turn per arm, radius 11 to 33 | |
| filament (stroke) | 6.5 | 1.0 px |
| spool (dot) | radius 8.5, beside the line's outer end (`attach="tangent"`, outer side), the line's outer edge flush with the spool's rim | 2.7 px |
| motion | spools lead clockwise; first at 120 deg | |
| circle | implied by the spools and the arms' outer ends (no ring) | |
| closest arms | 5.2 | 0.8 px |

The viewBox is `-50 -50 100 100`, and the mark reaches radius 46.6.

A (Sweep) holds best at 16 px and keeps the
S-swirl of the old logo. A2 (Spool) makes the dot a larger spool joined to a
thinner filament at its centre.

B (Orbit) puts the same idea inside a ring. The ring shrinks the arms by about
a sixth and fades to a faint circle at 16 px, so the implied circle wins.
C (Feed) leads the dots inward to a hub. That fits the AMS story, but it reads
more as four dots in a square plus four arcs.

## Colours

| bay | light set (default, PNGs, favicon) | dark set (`-dark` files) | docs spool colour |
|---|---|---|---|
| 1 | `#d9534f` | `#e8625d` | `#d9534f` |
| 2 | `#e8a01a` | `#f0b429` | `#f0b429` |
| 3 | `#3d8bd4` | `#5aa2e6` | `#3d8bd4` |
| 4 | `#3f9f5f` | `#52b673` | `#4fae6c` |

- The light set deepens the docs amber and green one step for white and
  `#f2f5f4`.
- The light set also holds on `#0d1315` (4.7:1 or better). That matters because
  a favicon can sit on a light or a dark tab strip.
- The dark set lifts red, blue and green so the four weigh evenly on dark
  backgrounds.
- Amber stays below 3:1 on white (2.2:1). Deepening it further would turn it
  brown.

## Which file where (`out/`)

| file | use |
|---|---|
| `openams-logo.svg` | default mark, any light background (also fine on dark) |
| `openams-logo-dark.svg` | dark backgrounds only, e.g. the docs' dark theme |
| `openams-logo-mono.svg` | one colour, `currentColor`: inherits the text colour when inlined |
| `openams-lockup.svg`, `openams-lockup-dark.svg` | mark + "OpenAMS", light / dark backgrounds |
| `favicon.ico` (16/32/48), `openams-logo-16/32/48.png` | browser favicon |
| `apple-touch-icon.png` | iOS home screen (180 px, opaque white, mark at 80 %) |
| `openams-logo-180.png`, `-192.png` | app icons, web manifest |
| `openams-logo-512.png`, `-1024.png` | social cards, README, anywhere a raster is needed |
| `openams-logo-A.svg`, `-A2.svg`, `-A3.svg`, `-B.svg`, `-C.svg` | the explored directions (A3 is the chosen one) |

The wordmark is Barlow Condensed Bold (700), the docs' heading font, set as
outlines. The glyph paths are embedded in `generate.py`, so no font is needed
to rebuild. Barlow is under the SIL Open Font License 1.1.

## Regenerate

```sh
python3 generate.py            # SVGs in out/ and preview.html
python3 generate.py --png      # also the PNGs, apple-touch-icon.png and favicon.ico
python3 generate.py --report   # contrast ratios and 16 px clearances; writes nothing
```

`--png` needs `rsvg-convert`, or ImageMagick (`magick` or `convert`), and
ImageMagick for the `.ico`.

To change the design, edit `DIRECTIONS`, `RECOMMENDED` or `PALETTES` in
`generate.py`. Every parameter is described in its docstring.
