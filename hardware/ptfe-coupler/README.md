# PTFE tube coupler v5

Joins the filament buffer's outlet tube to the tube that runs to the
printer's toolhead. Print `ptfe_coupler_v5.stl` (12 x 12 x 20 mm) and fit an
ECAS04 push-fit collet in each end, one per tube.

- The **3** end takes the 3 mm ID / 4 mm OD tube from the buffer.
- The **2** end takes the tube to the toolhead: 3 mm ID, or 2 mm ID for an
  extruder whose entrance only takes 2 mm ID tube (the Orbiter, for example).
- The arrows on the body point the way the filament travels, from 3 to 2.

Inside, the coupler tapers smoothly from 3 mm to 2 mm. Where 3 mm ID tube
meets 2 mm ID tube without it, the 1 mm step catches the filament tip.

Everything before the coupler must be 3 mm ID / 4 mm OD: narrower tube adds
too much friction for the AMS. [Set up a Cortex Bridge
printer](../../docs/guide/cortex-bridge-setup.md) shows where it goes.
